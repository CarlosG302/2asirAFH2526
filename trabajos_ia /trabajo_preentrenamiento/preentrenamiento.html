1. Configuración del Entorno y Hardware

El primer paso para entrenar una inteligencia artificial es la configuración del entorno de desarrollo. En este caso, se utiliza Python junto con la librería PyTorch. Es fundamental verificar que el sistema reconozca la aceleración por hardware.

Como se observa en el Administrador de Tareas, el uso de la GPU (NVIDIA GeForce RTX 4060 Ti) llega al 98% durante el proceso. Esto indica que el modelo está utilizando los núcleos CUDA para realizar los cálculos tensoriales, lo cual es significativamente más rápido que usar el procesador (CPU).

Imagen 1: Monitorización del rendimiento de la GPU y estructura del código en Python.

En el código fuente de la izquierda, se definen clases como Head(nn.Module), que representan las cabezas de atención del modelo, componentes clave de la arquitectura Transformer.

2. El Proceso de Entrenamiento (Loss Optimization)

El entrenamiento consiste en alimentar al modelo con fragmentos de texto (en este caso, del archivo quijote.txt) y pedirle que prediga el siguiente carácter. La diferencia entre su predicción y el texto real se mide mediante una función de pérdida llamada Loss.

En la consola podemos ver cómo el loss de entrenamiento y el loss de validación disminuyen drásticamente desde un valor de 4.9 hasta 1.35 después de 4500 iteraciones. Cuanto menor es el loss, mejor "entiende" la IA la estructura gramatical del texto original.

Imagen 2: Progreso del entrenamiento y primera generación de texto tras 4500 iteraciones.

Al finalizar las iteraciones, el modelo intenta generar texto. Aunque al principio puede parecer confuso ("NTú-In Narón..."), ya se observan estructuras que imitan el español antiguo y nombres propios como "Teresal".

3. Inferencia y Pruebas de Usuario

Una vez que el modelo está entrenado, pasamos a la fase de inferencia. Aquí es donde el usuario puede interactuar con la IA mediante un script de prueba (probar.py).

El sistema solicita un "inicio de frase" (prompt) y la IA intenta completarlo basándose en lo aprendido. En el ejemplo, al ingresar "Sancho Panza", el modelo responde con una estructura que evoca el estilo de Cervantes, mencionando a "Don Quijote".

Imagen 3: Interfaz de usuario para realizar inferencias con el modelo cargado.

Es importante notar que el entrenamiento de una IA es un proceso iterativo. Si el resultado no es coherente, se deben ajustar hiperparámetros como la tasa de aprendizaje (learning rate), el número de capas o aumentar el tiempo de entrenamiento.
