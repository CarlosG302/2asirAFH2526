Ajuste Fino de Modelo LLM (Phi-3)

Este documento detalla la práctica de pre-entrenamiento y ajuste fino (fine-tuning) para adaptar un modelo base a tareas específicas de un Asistente de Cocina mediante el uso de adaptadores de bajo rango (LoRA).

1. Arquitectura de Adaptación (LoRA)

Para optimizar el modelo sin re-entrenar todos los parámetros, se configuraron los siguientes hiperparámetros de la librería axolotl:

lora_r: 16
lora_alpha: 32
lora_dropout: 0.05
target_modules: [qkv_proj, o_proj, gate_up_proj, down_proj]
# Optimizador: adamw_torch
learning_rate: 0.0002

2. Rendimiento y Carga de Trabajo

Durante la fase de entrenamiento, se monitoreó la carga en la unidad de procesamiento gráfico para asegurar la estabilidad térmica y de memoria:

El uso de BF16 (Bfloat16) permitió mantener una alta velocidad de cómputo con un consumo de memoria optimizado.
