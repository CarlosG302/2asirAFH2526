Requisitos Previos

  • Python 3.10+ con PyTorch instalado (soporte CUDA para GPU).
  • Entorno GPU: NVIDIA con drivers CUDA actualizados.[file:4]
  • Editor: VS Code con extensiones para Python y Jupyter.
  • Librerías: torch, transformers, datasets (instalar via pip).

Errores Comunes y Soluciones

Error Solución
CUDA out of memory Reducir batch_size a 1, usar gradient_accumulation_steps=4
No GPU detectada torch.cuda.is_available() False → Actualizar drivers NVIDIA

Conclusión de la Práctica

El LLM se entrena exitosamente en GPU local. Guarda el modelo con model.save_pretrained(). Prueba inferencia para validar.[cite:6]
